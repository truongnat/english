# English Daily Coach 🎯

**Luyện tập tiếng Anh mỗi ngày — 7 bài học tương tác cho người mới bắt đầu**

## 📖 About

English Daily Coach là chương trình luyện tập tiếng Anh 7 ngày dành cho người mới bắt đầu, được thiết kế dưới dạng các trang HTML tương tác. Mỗi bài học bao gồm từ vựng, ngữ pháp, hội thoại thực tế và bài tập giúp bạn ghi nhớ sâu hơn thông qua các cơ chế:

- 🃏 **Flashcard** — Học từ vựng kèm IPA và ví dụ, click để lật thẻ
- 🎙️ **Phát âm** — Nghe phát âm chuẩn với Web Speech API
- 💬 **Hội thoại** — Đàm thoại thực tế, có thể ẩn/hiện bản dịch
- 📝 **Bài tập tương tác** — Trắc nghiệm, điền từ, ghép câu
- ✅ **Theo dõi tiến độ** — Lưu điểm số và streak trên trình duyệt

## 📅 Nội dung Tuần 1

| Day | Bài học | Mô tả |
|-----|---------|-------|
| 01 | Chào hỏi cơ bản | Basic Greetings |
| 02 | Giới thiệu bản thân | Self-introduction |
| 03 | Số đếm & Hỏi tuổi | Numbers & Asking Age |
| 04 | Hỏi thăm cảm xúc & tình trạng | Feelings & Status |
| 05 | Mô tả đồ vật bằng This / That | This / That & Objects |

| 07 | Ôn tập tổng hợp Tuần 1 | Week 1 Review |

## 🚀 Cách sử dụng

Mở `index.html` trong trình duyệt (hoặc truy cập GitHub Pages nếu đã deploy).

## 🛠️ Công nghệ

- HTML + CSS thuần
- Web Speech API (phát âm)
- Web Storage API (lưu tiến độ)

## 📦 Deploy

Repo được cấu hình sẵn để deploy lên **GitHub Pages** từ nhánh `main`.
